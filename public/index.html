📚 À Propos du PTP et du BMCA

▼

Qu'est-ce que le PTP ?

Le Precision Time Protocol (IEEE 1588) permet une synchronisation temporelle de précision nanoseconde sur Ethernet.

Qu'est-ce que le BMCA ?

Le Best Master Clock Algorithm détermine quelle horloge devient le Grandmaster selon une hiérarchie stricte.

Types d'Horloges

  • OC : Ordinary Clock
  • BC : Boundary Clock
  • TC : Transparent Clock
  • GM : Grandmaster

Critères BMCA (PTPv2)

  1. priority1
  2. clockClass
  3. clockAccuracy
  4. variance
  5. priority2
  6. clockIdentity
